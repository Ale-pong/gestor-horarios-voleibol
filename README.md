# 🏐 Gestor de Horarios y Asistencia de Voleibol

Este proyecto es un script en **Python** desarrollado para automatizar la gestión administrativa de un equipo de voleibol. Permite procesar la lista de jugadoras y generar hojas de asistencia organizadas en formato Excel de forma rápida y sin errores.

---

## 🛠️ Tecnologías y Herramientas
* **Python**: Lenguaje principal de programación.
* **Pandas**: Manipulación y estructuración de datos.
* **Microsoft Excel / Openpyxl**: Formato final para exportación de datos.

---

## 🚀 Funcionalidades Principales
1. **Lectura de datos:** Carga rápida de la lista de jugadoras desde un archivo CSV o Excel.
2. **Generación automatizada:** Creación de registros de asistencia para los entrenamientos.
3. **Exportación limpia:** Salida estructurada en un archivo de Excel para control interno.

---

## 📌 Impacto y Valor de Negocio
* **Ahorro de tiempo:** Reduce de minutos a segundos el tiempo necesario para preparar listas de asistencia manuales.
* **Cero errores:** Elimina fallos en la trascripción manual de nombres o números de camiseta.
* **Estandarización:** Ofrece un formato uniforme para el seguimiento administrativo.
